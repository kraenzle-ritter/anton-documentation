# Profile and personal settings

Your own profile opens through the username at the top right, then **Profile**. It has four tabs: **Profile**, **Security**, **Settings** and **History**.

## Profile

Name, username, e-mail address and role of the account, and the number of sign-ins. **Edit** changes name, e-mail address and password; for a change Anton asks for the current password.

## Security

[Two-factor authentication](2FA.md), the recovery codes, the [passkeys](passkey.md) and the open sessions. **End all other sessions** signs you out on every other device.

## Settings

The settings apply to your own account only and take effect at once: every row has a switch or a choice on the right, and a change is kept without saving. Some rows only appear when the archive has switched the function on or the role needs it.

### Display

| Setting | Effect |
|---|---|
| Items per page | how many rows a list shows; «Default» takes the archive's setting |
| Hide comments in the detail view | hides the [comments](comments.md) in the detail view (only when comments are switched on) |
| Hide the «?» for page help in the navigation | hides the «?» beside «Help» that leads to the matching page of this documentation |
| Hide the «Archive tree» button | hides the [archive tree](hierarchy.md#archivbaum) beside the path (only where the archive offers it) |

### Editing

| Setting | Effect |
|---|---|
| Show all locales in edit forms | shows multilingual fields in all languages at once (only with multilingual content) |
| Disable bulk actions | hides [selection and bulk actions](selection.md) |
| Hide the «Text snippet» button at the text fields | hides the text snippets below the text fields (from the role editor) |
| Show field help in edit forms | shows the help texts below the fields of the form, see [forms](forms.md) |
| Hide the «update table» download in the result list | hides the download for the [update import](import.md) (admins only) |
| Disable QR upload | hides the upload by QR code (only where the archive uses it) |

### Search

| Setting | Effect |
|---|---|
| Weighted search | [weighted search](weighted-search.md) on or off; «Default» takes the archive's setting |

## History

The records the account edited last. From the role editor the list can be downloaded as a Word file.
