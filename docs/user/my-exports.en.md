# My exports

Some exports are too large for a direct download. Anton then builds them in the background and files them under **Data export → My exports** (`/export/mine`).

## Which exports

| Export | in the background above |
|---|---|
| Word finding aid | 1,000 records in the subtree |
| EAD, CIDOC CRM, RiC, Memobase (download area of a record) | 1,000 records in the subtree |
| DIP (BagIt), OCFL | 500 media |
| Excel export of a result list, including the update table | 1,000 rows |

Below that the download comes at once, as before. Operations sets the limits per archive; the values above are the defaults. The E-ARK DIP has its own setting and appears under **Data export → E-ARK DIP** (see [Downloading a DIP](download-dip.md)).

## How it works

1. Start the download as usual.
2. Instead of the file, a message says the export is being built in the background, with a link to **My exports**.
3. Once the export is ready, it is in the list there, with name, size and date. The list refreshes by itself.
4. Download or delete it.

Starting the same export again before the first one is done shows a notice; the export is not built twice.

## Who sees what

The list shows your own exports only. An export is built with the rights of the person who started it and holds the same as the direct download.

The files are deleted after **7 days**.
