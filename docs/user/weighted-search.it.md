# Ricerca ponderata

La ricerca ponderata migliora i risultati nelle viste a elenco ordinando i risultati in base alla loro rilevanza. Quanto più un termine di ricerca corrisponde a una scheda, tanto più in alto essa compare nell'elenco dei risultati.

## Ambiti di applicazione

La ricerca ponderata è disponibile per:

- **attori e attrici** (Actors)
- **luoghi** (Places)
- **parole chiave** (Keywords)

## Come funziona

Il sistema valuta i risultati secondo diversi criteri:

| Tipo di corrispondenza | Valutazione |
|------------|-----------|
| **Corrispondenza esatta** | Rilevanza massima (3×) |
| **Corrispondenza a inizio parola** | Rilevanza elevata (2×) |
| **La corrispondenza contiene il termine** | Rilevanza di base (1×) |

**Esempio**: cercando «Müller»:

1. Un attore o un'attrice di nome «Müller» (esatto) compare in cima
2. Seguito da «Müller-Weber» (inizia con)
3. Poi «Anna Müller» (contiene)

Inoltre i vari campi vengono ponderati in modo diverso. Il nome di un attore o di un'attrice conta ad esempio più di una corrispondenza nella descrizione.

## Attivazione

### Nella vista a elenco

1. Aprire la vista a elenco desiderata (ad es. attori e attrici)
2. Inserire un termine nel campo di filtro
3. Sotto il campo di ricerca compare la casella di controllo **«Ordina per rilevanza»**
4. Attivare la casella per ordinare i risultati per rilevanza

!!! note "Nota"
    La casella di controllo compare solo quando una ricerca è attiva.

### Come impostazione predefinita nelle impostazioni personali

La ricerca ponderata può essere definita come impostazione personale predefinita:

1. Fare clic sul proprio profilo (in alto a destra)
2. Scegliere **Profilo / Account**
3. Andare in **Impostazioni**
4. Alla voce **«Ricerca ponderata»** scegliere una delle opzioni:
   - **Predefinita**: utilizza l'impostazione globale dell'archivio
   - **Attiva**: la ricerca ponderata è sempre attivata
   - **Disattivata**: la ricerca ponderata è sempre disattivata

!!! tip "Suggerimento"
    Con l'opzione «Predefinita» si riprende automaticamente l'impostazione configurata per il proprio archivio. Si beneficia così anche degli adeguamenti futuri decisi dall'amministrazione.

## Suggerimenti

- La ricerca ponderata è particolarmente utile con **nomi frequenti** o **termini generici**
- Per la ricerca di **segnature esatte** o **ID** l'ordinamento normale è spesso più utile
- L'impostazione può essere commutata in qualsiasi momento per ogni ricerca tramite la casella di controllo
