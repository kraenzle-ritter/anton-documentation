# Profil et paramètres personnels

Le profil s’ouvre par le nom d’utilisateur en haut à droite, puis **Profil**. Il compte quatre onglets : **Profil**, **Sécurité**, **Paramètres** et **Historique**.

## Profil

Nom, nom d’utilisateur, adresse e-mail et rôle du compte, ainsi que le nombre de connexions. **Modifier** permet de changer le nom, l’adresse e-mail et le mot de passe ; Anton demande pour cela le mot de passe actuel.

## Sécurité

L’[authentification à deux facteurs](2FA.md), les codes de récupération, les [passkeys](passkey.md) et les sessions ouvertes. **Terminer toutes les autres sessions** vous déconnecte de tous les autres appareils.

## Paramètres

Les paramètres ne valent que pour votre compte et s’appliquent aussitôt : chaque ligne porte à droite un interrupteur ou un choix, une modification est reprise sans enregistrer. Certaines lignes n’apparaissent que si l’archive a activé la fonction ou si le rôle en a besoin.

- **Affichage** : nombre d’entrées par page (« Standard » reprend la valeur de l’archive), masquer les commentaires dans la vue détaillée, masquer le « ? » de l’aide dans la navigation, masquer le bouton « Arborescence ».
- **Édition** : afficher les champs dans toutes les langues, désactiver les [actions groupées](selection.md), masquer le bouton « Module de texte », afficher l’aide des champs, masquer le téléchargement « tableau de mise à jour » (admins), désactiver l’upload par code QR.
- **Recherche** : [recherche pondérée](weighted-search.md) activée ou non ; « Standard » reprend la valeur de l’archive.

## Historique

Les enregistrements que le compte a modifiés en dernier. À partir du rôle d’éditeur·trice, la liste se télécharge en fichier Word.
