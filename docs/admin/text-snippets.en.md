# Text snippets

Text snippets are recurring wordings that can be inserted into the text fields of a record while editing it, for example «The provenance is not recorded.» or a standard sentence on the conditions of use.

## Keeping them

Under **Administration › Configuration › Text snippets** the administration creates the snippets, from the role admin on. A snippet has:

- a **title**, under which it appears when inserting;
- the **text**, several lines, with Markdown as in the text fields;
- the **fields** it is offered in. With none chosen, it appears in every text field.

The order on the page is the order when inserting.

## Inserting

In the edit form, below every text field that has snippets, there is the button **Text snippet**, from the role editor on. It opens the list of snippets for that field; a click inserts the text at the cursor and replaces a selection. The text can then be edited like any other.

Whoever does not need the snippets hides the button in their own profile under **Settings**.
