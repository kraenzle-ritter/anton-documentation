# Anton – Documentation

Anton is a web-based, multilingual and standards-oriented archival database. Anton can be used [as a service](faq/anton_as_service.md) on a server operated by [k & r](https://www.k-r.ch), or run [on premises](faq/anton_on_premises.md) on an institution's own server.
