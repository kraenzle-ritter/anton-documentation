# Importazione

## Migrazione da un'altra banca dati

La migrazione da una banca dati a una nuova comporta sempre un impegno relativamente elevato. I dati devono essere mappati, in parte preparati e/o rielaborati e, se necessario, corretti. Allo stesso tempo una migrazione rende visibili le debolezze dei dati e li rende più omogenei. In questo senso una migrazione di banca dati offre l'opportunità di migliorare la qualità dei dati.

Quale strategia di migrazione sia la più adatta va deciso caso per caso. Con Anton abbiamo realizzato con successo le seguenti soluzioni:

1. Esportazione della vecchia banca dati in file Excel – importazione Excel in Anton  
2. Esportazione della vecchia banca dati in file EAD – importazione EAD in Anton  
3. Ripresa diretta dei dati dalla vecchia banca dati  

Per i metodi 2 e 3 occorre programmare e/o adattare degli script.

## Importazione da Excel

Anton dispone di un'importazione Excel articolata e ben documentata. Anche i lavori di descrizione più estesi sullo stesso livello vengono spesso svolti in Excel. Il file Excel viene poi validato e i dati importati in Anton.

Con l'importazione Excel è possibile importare anche oggetti digitali (fotografie, documenti ecc.).

## Importazione da SIP (eCH-0160)

Anton supporta l'importazione di pacchetti SIP nel formato eCH-0160. In questo modo è possibile riprendere in Anton fondi archivistici gestiti in altri sistemi. Cfr. anche [Importazione SIP in Anton](../user/sip.md).

## Archivi di file

Esiste un'importazione per gli archivi di file. In Anton viene ricostruita la gerarchia della struttura di cartelle. I singoli file diventano unità documentarie. Questa importazione non è al momento ancora disponibile tramite browser.
