# Pacchetti open source per ANTON

Per Anton sviluppiamo costantemente pacchetti open source, che pubblichiamo con una licenza libera (per lo più MIT):

## Pacchetti kraenzle-ritter

### [kraenzle-ritter/markdown-to-ead](https://github.com/kraenzle-ritter/markdown-to-ead)

Converte documenti Markdown nel formato XML EAD (Encoded Archival Description). Consente di integrare frammenti Markdown negli strumenti di ricerca EAD.

### [kraenzle-ritter/markdown-to-tei](https://github.com/kraenzle-ritter/markdown-to-tei)

Converte frammenti Markdown nel formato XML TEI (Text Encoding Initiative). Utile per l'edizione digitale di testi e per le pubblicazioni scientifiche.

### [kraenzle-ritter/nara-risk](https://github.com/kraenzle-ritter/nara-risk)

Implementa la valutazione del rischio della NARA (US National Archives and Records Administration) per i formati di file digitali. Valuta i formati (PRONOM ID) in base alla loro sostenibilità e al rischio per la conservazione a lungo termine.

### [kraenzle-ritter/puidentify](https://github.com/kraenzle-ritter/puidentify)

Wrapper PHP per Siegfried e/o Fido per l'identificazione dei formati di file tramite PRONOM ID. Consente di determinare con precisione i formati per la conservazione digitale a lungo termine.

### [kraenzle-ritter/resources](https://github.com/kraenzle-ritter/resources)

Pacchetto per la memorizzazione e la gestione di link verso file e banche dati di autorità (come GND, Geonames, Wikipedia, Metagrid).

### [kraenzle-ritter/sipper](https://github.com/kraenzle-ritter/sipper)

Parser SIP (Submission Information Package) secondo eCH-0160.

### [kraenzle-ritter/timelogger](https://github.com/kraenzle-ritter/timelogger)

Utility di logging per il monitoraggio delle prestazioni e la misurazione dei tempi in ANTON.

## Pacchetti ottosmops

### [ottosmops/antondate](https://github.com/ottosmops/antondate)

Elaborazione e validazione delle date specifiche per ANTON. Supporta diversi formati di data e datazioni approssimative (ad es. «ca. 1920», «1920-1930»).

### [ottosmops/consoleoutput](https://github.com/ottosmops/consoleoutput)

Utility per gli output su console nei comandi Artisan di Laravel.

### [ottosmops/ids](https://github.com/ottosmops/ids)

Utility per l'analisi di indicazioni numeriche con separatori e caratteri di intervallo.

### [ottosmops/office2text](https://github.com/ottosmops/office2text)

Estrazione del contenuto testuale da file Microsoft Office (Word, Excel, PowerPoint) per l'indicizzazione full text. Rende consultabili i documenti Office in ANTON.

### [ottosmops/pdftotext](https://github.com/ottosmops/pdftotext)

Estrazione del contenuto testuale da file PDF per l'indicizzazione full text. Wrapper PHP per lo strumento a riga di comando pdftotext.

### [ottosmops/pdftothumb](https://github.com/ottosmops/pdftothumb)

Generazione di miniature da file PDF. Crea le immagini di anteprima visualizzate in ANTON.

### [ottosmops/pdfunite](https://github.com/ottosmops/pdfunite)

Unione di più file PDF in un unico documento. Wrapper PHP per lo strumento a riga di comando pdfunite.

### [ottosmops/pdfvalidate](https://github.com/ottosmops/pdfvalidate)

Validazione dei file PDF per verificarne l'integrità strutturale e la conformità agli standard PDF. Individua i PDF danneggiati o problematici prima dell'archiviazione.

### [ottosmops/settings](https://github.com/ottosmops/settings)

Gestione centralizzata delle impostazioni di configurazione di ANTON. Consente configurazioni e adattamenti specifici per cliente.

### [ottosmops/xmltoolkit](https://github.com/ottosmops/xmltoolkit)

Toolkit per l'elaborazione e la trasformazione di documenti XML.

### [ottosmops/xmlvalidator](https://github.com/ottosmops/xmlvalidator)

Validazione di documenti XML rispetto a schemi XML (XSD). Garantisce che i dati XML esportati siano conformi agli standard archivistici.

## Pacchetti ritterg

### [ritterg/sru-ao](https://github.com/ritterg/sru-ao)

Client SRU (Search/Retrieve via URL) per Archives Online (portale svizzero degli archivi). Consente la ricerca e lo scambio di dati con il portale svizzero degli archivi e altri sistemi compatibili con SRU.
