# General FAQs

## Web-based

Anton is designed as a web database, which means that not only research but also editing and modifying data take place over the internet. A current browser and an internet connection are all that is needed to work with Anton in full.

## Multi-user

Customers receive an admin account that can be used to create any number of new users with different permissions (user, internal user, editor, admin).

## Archival portals

Data export to EAD is aligned with the requirements of the [European archives portal](http://www.apex-project.eu). In Switzerland, participation is coordinated by the Swiss Federal Archives.

Anton also supports participation in «[Archives Online](https://archives-online.org)».
