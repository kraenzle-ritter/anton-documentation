# Search and use

## Web search for the public

By default, Anton displays a simple search form on the home page. In addition, there is an «advanced search» in which various criteria can be combined.

## Display of the archival arrangement

From every record, navigation is possible via the display of the «path» to every «ancestor» as well as to all children, which are listed below the detail view.

Anton does not currently have a tree view of the entire archive. Nevertheless, the archival context is represented in Anton and it is possible to browse the arrangement. Programming a tree view is fundamentally feasible. Experience shows that this form of display is desired above all by archival professionals, whereas ordinary users do not miss it.

## Searching individual data elements and full-text search

Searching individual data elements is possible. There is also a full-text search, which covers attached Office documents and PDFs as far as these contain embedded text (e.g. from OCR).

## Restricting the search to individual recordgroups or fonds

Restricting the search to individual recordgroups or fonds is possible.

## Cart

There is a simple cart. Orders are placed by e-mail to the archive.

## Loans

Loans can be managed as well. Borrowers must be registered users.
