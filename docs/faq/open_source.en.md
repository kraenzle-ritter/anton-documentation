# Open source packages for ANTON

We continuously develop open source packages for Anton and publish them under an open source licence (usually MIT):

## kraenzle-ritter packages

### [kraenzle-ritter/markdown-to-ead](https://github.com/kraenzle-ritter/markdown-to-ead)

Converts Markdown documents into the EAD (Encoded Archival Description) XML format. Allows Markdown fragments to be integrated into EAD finding aids.

### [kraenzle-ritter/markdown-to-tei](https://github.com/kraenzle-ritter/markdown-to-tei)

Converts Markdown fragments into the TEI (Text Encoding Initiative) XML format. Useful for digital scholarly editions and academic publications.

### [kraenzle-ritter/nara-risk](https://github.com/kraenzle-ritter/nara-risk)

Implements the NARA (US National Archives and Records Administration) risk assessment for digital file formats. Rates file formats (PRONOM ID) according to their sustainability and their risk for long-term preservation.

### [kraenzle-ritter/puidentify](https://github.com/kraenzle-ritter/puidentify)

PHP wrapper for Siegfried and/or Fido for identifying file formats via PRONOM IDs. Enables precise determination of file formats for digital preservation.

### [kraenzle-ritter/resources](https://github.com/kraenzle-ritter/resources)

Package for storing and managing links to authority files and databases (such as GND, Geonames, Wikipedia, Metagrid).

### [kraenzle-ritter/sipper](https://github.com/kraenzle-ritter/sipper)

SIP (Submission Information Package) parser (eCH-0160).

### [kraenzle-ritter/timelogger](https://github.com/kraenzle-ritter/timelogger)

Logging utility for performance monitoring and time measurement in ANTON.

## ottosmops packages

### [ottosmops/antondate](https://github.com/ottosmops/antondate)

Date processing and validation specifically for ANTON. Supports various date formats and approximate datings (e.g. "ca. 1920", "1920-1930").

### [ottosmops/consoleoutput](https://github.com/ottosmops/consoleoutput)

Utility for console output in Laravel Artisan commands.

### [ottosmops/ids](https://github.com/ottosmops/ids)

Utility for parsing numeric specifications with separators and range characters.

### [ottosmops/office2text](https://github.com/ottosmops/office2text)

Extraction of text content from Microsoft Office files (Word, Excel, PowerPoint) for full-text indexing. Makes Office documents searchable in ANTON.

### [ottosmops/pdftotext](https://github.com/ottosmops/pdftotext)

Extraction of text content from PDF files for full-text indexing. PHP wrapper for the pdftotext command-line tool.

### [ottosmops/pdftothumb](https://github.com/ottosmops/pdftothumb)

Generation of thumbnail images from PDF files. Creates preview images for display in ANTON.

### [ottosmops/pdfunite](https://github.com/ottosmops/pdfunite)

Merging of several PDF files into a single document. PHP wrapper for the pdfunite command-line tool.

### [ottosmops/pdfvalidate](https://github.com/ottosmops/pdfvalidate)

Validation of PDF files for structural integrity and conformity with PDF standards. Detects damaged or problematic PDFs before archiving.

### [ottosmops/settings](https://github.com/ottosmops/settings)

Central management of configuration settings for ANTON. Enables customer-specific configurations and adaptations.

### [ottosmops/xmltoolkit](https://github.com/ottosmops/xmltoolkit)

Toolkit for processing and transforming XML documents.

### [ottosmops/xmlvalidator](https://github.com/ottosmops/xmlvalidator)

Validation of XML documents against XML schemas (XSD). Ensures that exported XML data conforms to archival standards.

## ritterg packages

### [ritterg/sru-ao](https://github.com/ritterg/sru-ao)

SRU (Search/Retrieve via URL) client for Archives Online (Swiss archives portal). Enables searching and data exchange with the Swiss archives portal and other SRU-compatible systems.
