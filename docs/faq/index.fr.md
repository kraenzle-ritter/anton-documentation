# FAQ générales

## Application web

Anton est conçu comme une base de données web : non seulement la recherche, mais aussi la saisie et la modification des données se font via internet. Un navigateur récent et une connexion internet suffisent pour travailler pleinement avec Anton.

## Multi-utilisateur

Chaque client·e reçoit un accès administrateur permettant de créer un nombre illimité de nouveaux comptes avec différentes autorisations (utilisateur·trice, utilisateur·trice interne, éditeur·trice, administrateur·trice).

## Portails d'archives

L'export des données en EAD est aligné sur les exigences du [portail européen des archives](http://www.apex-project.eu). En Suisse, la participation est coordonnée par les Archives fédérales.

Anton permet également de participer à «&nbsp;[Archives Online](https://archives-online.org)&nbsp;».
